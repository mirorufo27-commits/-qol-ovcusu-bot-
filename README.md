# Qol Ovçusu — Minimal implementasiya

Bu repo hazırda ilkin skeleton layihəsini ehtiva edir. Yeni fayllar əlavə olunub: Telegram bot, DB modelləri, API wrapper, qiymətləndirmə və testlər.

İstifadə:

1. .env faylını yaradın (və ya `cp .env.example .env`) və TELEGRAM_TOKEN və FOOTBALL_API_KEY dəyişin.
2. Python 3.9+ istifadə edin.
3. Virtualenv yaradın və asılılıqları quraşdırın:
   pip install -r requirements.txt
4. DB yaradın və ilkin cədvəlləri qurun: python main.py --init-db
5. Botu işlədin: python main.py

Ətraflı təlimatlar repository README.md-dədir.
